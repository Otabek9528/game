    Know what the free test shows

    5 minutes

    Read this once, so a green build doesn't promise more than it can.

    1. It's the App Store, not the Play Store.

      iPhone apps are published through Apple's App Store Connect. The US$99 a year is the Apple Developer Program. Google Play is only for Android, which you already have.

    2. The free build can't go on your iPhone.

      Without the paid program, Apple doesn't let any app be installed on a real iPhone. The free test runs the app on an iPhone simulator (an iPhone on Codemagic's Mac) and gives you screenshots. The simulator has no camera or compass and gets no notifications, so those are tested later, on your phone, through TestFlight.

    3. The iPhone widget isn't in this build yet.

      Its code is ready, but adding it to the project normally needs Xcode on a Mac. The app works without it, and the "add widget" card stays hidden on iPhone until it's there. If you want it in the first release, tell me: I can add it to the project myself, and the free check will show whether it builds.

    4. Codemagic's free plan gives about 500 build minutes a month on its Macs. One free check takes roughly 20–35 minutes, so you have room for well over ten runs a month.

    2. Copy the last 60 lines or so (the first lines that say error are what matters) and send them to me with the step's name. If the failed step is Run on an iPhone simulator, also download iphone_log.txt from Artifacts and send it.

    Join the Apple Developer Program

    30 minutesusually 1–2 days for Apple
    1. An Apple ID with two-factor authentication.

      Use the Apple ID you'll keep for the app. If you have an iPhone, it's the one in Settings → your name; two-factor is on there by default. The name on it should be your legal name.

    2. The easiest way is the Apple Developer app on an iPhone (from the App Store) → Account → Enroll now: it scans your ID and takes the payment through your Apple ID. Without an iPhone, use developer.apple.com/programs/enroll.
    3. Entity type: Individual / Sole Proprietor.

      Your own name appears as the seller on the App Store. An organization would need a D-U-N-S company number, which takes weeks.

    4. Pay the US$99 (a Visa or Mastercard works). It renews every year; if it lapses, the app leaves the App Store.
    5. Wait for the email Welcome to the Apple Developer Program. Then sign in once at appstoreconnect.apple.com and accept any agreement it shows (Business → Agreements: the Free Apps agreement must be Active; a free app needs no bank or tax details).

    Connect Codemagic to Apple

    15 minutes

    An App Store Connect API key lets Codemagic sign the app and upload it for you. It works like a password for your Apple account's app side.

    The key file (.p8) is a password. Apple lets you download it once. Keep it in a safe place, upload it only to Codemagic, and don't send it to anyone, me included.

    Make the key

    appstoreconnect.apple.com → Users and Access → Integrations → App Store Connect API → Team Keys
    1. The first time, click Request Access and accept (instant for the account holder).
    2. Click + (Generate API Key). Name Codemagic, Access App Manager → Generate.
    3. Note the Issuer ID (above the list) and the key's Key ID. Click Download and keep the file AuthKey_XXXXXXXXXX.p8.

    Give it to Codemagic

    Codemagic → Team settings (your account's settings) → Team integrations → Developer Portal → Connect
    1. App Store Connect API key name: exactly this (the build settings look for it by name):
      Key name
      Vegukin App Store Connect
    2. Fill in the Issuer ID and Key ID, choose the .p8 file → Save.

    Set up signing

    15 minutes

    Every iPhone app is signed with a certificate (who made it) and a provisioning profile (which app it is and what it may do). Codemagic keeps both and applies them when it builds.

    The certificate

    Codemagic → Team settings → codemagic.yaml settings → Code signing identities → iOS certificates
    1. Click Generate certificate, choose the key Vegukin App Store Connect, type Apple Distribution. Give it a reference name, e.g. vegukin_distribution → Create.
    2. Codemagic offers to download the certificate (.p12) with its password: download it and keep both with the .p8. You'd need them only if you ever leave Codemagic.

    The provisioning profile

    developer.apple.com/account → Profiles → +
    1. Under Distribution choose App Store Connect → Continue. App ID com.vegukin.muslimVegukin → Continue.
    2. Certificate: the one Codemagic just made (Apple Distribution, today's date) → Continue. Name Muslim Vegukin App Store → Generate. No need to download it.
    3. Back in Codemagic → Code signing identities → iOS provisioning profiles → Fetch profiles → choose the key → tick Muslim Vegukin App Store → Download selected.

    TestFlight on your iPhone

    10 minutes25–35 minutes building, then ~15 for Apple

    The workflow iOS to TestFlight builds the signed app and uploads it. TestFlight is Apple's app for installing test builds; nobody else sees them.

    1. Codemagic → Start new build → same branch → workflow iOS to TestFlight → Start.
    2. When it's green, App Store Connect → your app → TestFlight. The build shows Processing for 10–30 minutes, then Ready to Submit or Testing.
    3. Under Internal Testing click +, name the group Me, add yourself, and add the build to the group.
    4. On your iPhone install TestFlight from the App Store, sign in with the same Apple ID, open the invitation email → Install.
    5. Test on the phone: language choice and location; prayer times and a reminder set a minute ahead; the Qibla compass (flat, then the camera view); a barcode scan; Telegram and WhatsApp sign-in; sharing the app. Write down anything wrong and send it to me with screenshots.
    Notifications from the server and Google sign-in need the Firebase and Google values for iPhone first (mobile/ios/IOS.md, step 2). Send me the four values from GoogleService-Info.plist (API_KEY, GOOGLE_APP_ID, CLIENT_ID, REVERSED_CLIENT_ID); they are not secret. The APNs .p8 key goes only to the Firebase console, never to me.
    Each new TestFlight build: change the code, push, and start the workflow again. The build number goes up by itself.

    Submit to the App Store

    1–2 hoursreview: usually 1–3 days

    First, two things Apple's review would reject

    1. Sign in with Apple.

      Apple requires it in apps that offer Google, Telegram or similar sign-in (App Review Guideline 4.8). It's a button in the sign-in sheet plus a check on the server. Ask me to add it before you submit; TestFlight doesn't need it.

    2. The donation page.

      Apple rejects donations to an app's developer that bypass in-app purchase, unless the developer is a registered charity (Guideline 3.1.1). Ask me to hide it on iPhone.

    The App Store page

    App Store Connect → your app → App Store tab → iOS App 1.0
    1. Screenshots for a 6.9-inch iPhone (1320 × 2868 pixels), at least 3. Take them on your iPhone if it's a Pro Max; otherwise ask me, and I'll add a Codemagic step that makes them on the simulator.
    2. Texts: the Play Store descriptions fit (the Play launch guide has them with Copy buttons). Subtitle, 30 characters at most:
      Subtitle
      Prayer times, qibla, HiKorea
    3. Privacy policy URL:
      URL
      https://vegukin-twa.pages.dev/privacy.html
      Category Lifestyle. Age rating: answer the questions (all "None"; user-generated content: yes).
    4. App Privacy: the same data as Play's Data safety form: location, name, email, phone number, user ID, photos or videos, other user content, product interaction, device ID. None is used for tracking; all are linked to the user.
    5. Under Build, pick the TestFlight build you tested. In App Review Information, paste:
      Review notes
      Signing in is optional; most features work without it. Telegram and WhatsApp sign-in need the reviewer's own account. Google sign-in and Sign in with Apple work with any account.
    6. Add for Review → Submit. If Apple writes back with a rejection, send me its text: most are fixed in one round.

    If something goes wrong

    "Integration … not found" or "No App Store Connect API key"
    The key's name in Codemagic must be exactly Vegukin App Store Connect (phase 6). Rename it there, or tell me the name you used.
    "No matching profiles found" or "doesn't include … App Groups / aps-environment"
    The App ID is missing a capability, or the profile was made before you ticked it. Check phase 5 (App Groups configured, Push Notifications on), then make a new profile and fetch it again (phase 7).
    "The bundle version must be higher than the previously uploaded version"
    Something was uploaded outside Codemagic with a higher build number. Start the workflow again; if it repeats, tell me.
    The free minutes ran out
    They come back at the start of each month. Run the free check only after I tell you a fix is pushed, so each run counts.
    "Run on an iPhone simulator" failed
    The app crashed or closed on the simulator. Send me iphone_log.txt and the screenshots from Artifacts.
    Anything else
    Send me the failed step's name and the last 60 lines of its log. Never send the .p8, the .p12 or its password.
